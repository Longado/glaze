## 提示词

Create a single high-resolution art-direction reference image for the original Glaze mascot, using the attached banner only as an identity and layout reference. Landscape 3:1 composition, maximum native resolution. This is a visual redesign reference for a GitHub README loop.

Preserve: exactly ONE large expressive eye, a friendly tiny curved smile, a lavender/periwinkle softly squared pebble-shaped body, no arms or legs, the mascot on the middle-right and one desktop monitor at the far right. The monitor is in its frosted privacy state. Keep the left 42 percent quiet and empty so we can add exact project typography separately. No text, no lettering, no logos, no decorative UI labels.

Art direction: a premium little collectible desk companion photographed in a soft studio. Sophisticated soft-touch glazed resin, a subtle translucent lilac edge, rounded sculpted volume, delicate micro-roughness, broad softbox highlights rather than painted white strokes, believable lavender and cool blue bounce light, softly occluded contact shadows. The body should feel tactile and charming, never wet, metallic, neon, or hard plastic. One large creamy-white eyeball with a dimensional deep indigo iris, dark glossy pupil, two elegant reflected highlights, a subtle eyelid/socket, friendly curious expression. Preserve its simple recognizable silhouette; do not add a second eye or extra facial features.

Render the matching monitor as a beautifully rounded dark slate/periwinkle aluminum object with a substantial softly beveled rim, an understated stand, and real-looking translucent frosted glass. Soft indistinct silhouettes behind the glass, a simple subtle lock glyph, gentle reflections and lit glass edges. Clean airy near-white lavender background (#f3f5fa), no environment clutter, no pedestals. Orthographic or very mild three-quarter product illustration, coordinated light from upper left. Keep character and monitor at the same visual scale and arrangement as the reference but greatly improve the material, form, and lighting. The result should feel warm, refined, and cute, with crisp edges and physically convincing depth.
